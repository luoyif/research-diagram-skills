# 质量证据与限制

单元测试PASS表示代码在用例中的行为符合预期；几何PASS表示静态检查未发现所覆盖的问题；视觉复核PASS表示真实审阅者查看本次实际导出后作出的声明。三者不混用，也不证明科研结论正确。

必查：原文与关系方向；原生可编辑性；父子层级与遮挡；边穿节点、叠线、意外交叉；真实字体及两级字号；每种输出自己的实际预览；在最终插入尺寸下的可读性。

静态检查可能漏掉复杂字体度量、任意图标和语义错误。没有实际预览就是PENDING。源文件变化须重导出，不能沿用旧签名。复核写真实身份、所看文件和具体问题，单一代理不自称独立双人检查。

上游快照逐文件校验SHA256；保留源码不表示其全部脚本已运行。CI只做无桌面测试，不能把CI成功说成Draw.io或PowerPoint原生渲染已通过。
